# Submission Checklist

## Kaggle Writeup

Requirements:

- Title
- Subtitle
- Track selected
- Under 1,500 words
- Architecture explained
- Gemma 4 usage explained
- Challenges and solutions explained
- Real-world utility demonstrated

Sections:

- Problem
- Solution
- Demo workflow
- Architecture
- Gemma 4 usage
- Offline/local design
- Classroom-tuning approach
- Benchmarks
- Limitations
- Future work

## Video

Requirements:

- Public YouTube link
- No login required
- 3 minutes or less
- Attached to Media Gallery

Checklist:

- Story is understandable in first 30 seconds.
- App is shown working.
- Offline/local claim is demonstrated.
- Technical proof is visible.
- Impact is emotionally clear.

## Public Code Repository

Requirements:

- Public GitHub or Kaggle Notebook
- No login/paywall
- Clear README
- Setup instructions
- Model instructions
- Dataset/eval instructions if applicable

Checklist:

- App code included.
- Gemma integration code included.
- Sample inputs included.
- Evaluation script/results included.
- Fine-tuning notebook included if applicable.
- License file included.

## Live Demo

Options:

- Hosted web demo
- APK download
- Local run instructions
- Kaggle Notebook demo

Checklist:

- Judge can experience the app without private credentials.
- Sample textbook pages are included.
- Demo can run even if local model setup is heavy.
- Real Gemma mode is documented.

## Media Gallery

Required:

- Cover image

Recommended:

- Product screenshot
- Architecture diagram
- Before/after output comparison
- Offline mode screenshot
- Demo video thumbnail

## Final Link Test

Before submission:

- Open YouTube link in incognito.
- Open GitHub repo in incognito.
- Open live demo in incognito.
- Check Kaggle attachments.
- Verify writeup word count.
- Verify all links are public.
